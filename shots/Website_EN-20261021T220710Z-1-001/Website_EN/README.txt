Promptlyss website screenshot showcase — English

Six transparent PNG device mockups are built from the 1080x1920 game screenshots.
The existing layout and artwork are retained; the leaderboard image is edited
with illustrative display names while keeping its rank order and scores. Only an
edge-to-edge titanium / cobalt phone frame and soft shadow are added. There is no
notch, Dynamic Island, status bar, home indicator, or safe-area overlay.
